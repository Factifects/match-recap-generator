### SCENE 1

**Scene Type:** Code

**Narration:** Quick one — what does this print? You'd think array plus array does something array-ish. It doesn't — the plus sign converts each one to a string first, and an empty array turns into nothing at all. That's the whole trick.

### SCENE 2

**Scene Type:** Code

**Narration:** Two — stop nesting ifs. You'd think more conditions means clearer logic. Actually, your brain has to hold every outer if in memory just to understand the last line. Flip it: return early at the top, and you only ever hold one condition at a time.

### SCENE 3

**Scene Type:** Code

**Narration:** Three — stop console-logging arrays of objects. You'd think console.table just prints it more neatly. It's actually doing real work — scanning your objects for shared keys and building real columns out of them. That's why it lines up.
